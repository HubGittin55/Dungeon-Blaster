# Dungeon Blaster

Voice-driven LLM-run tabletop RPG, four players on one Windows 11 laptop.

- `docs/tools.md` - the `resolve_round` contract. Read first.
- `game/schema/resolve_round.schema.json` - the schema the DM is held to.
- `rules/` - the versioned rules document (law, not lore). Not written yet.
- `.pi/extensions/pi-gm/` - the pi GM: tracker, gate, turn state machine.
- `spikes/` - measurement spikes that answered an architecture question. Keep them.
- `notes/` - benchmark evidence for every number quoted in the architecture document.

Slice 1 (harness and law) is next: four slots, text-only rounds, validated crafting, evil bots.
